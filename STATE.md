# Состояние проекта Lexa

Обновлено: 29.10.2026. Фаза 4 закончена, ждём «ок» владельца на фазу 5.

## Готово
- **Фаза 0** – `docs/ARCHITECTURE.md`, `docs/adr/0001-dictionary-sources.md`, `docs/DESIGN_TOKENS.md`.
- **Фаза 1** – скелет, тема, навигация, Room, пустые экраны, Roborazzi (20 скриншотов). Круг критики сделан:
  контраст маркера в тёмной теме, русские склонения на любом языке устройства.
- **Фаза 2 (код)** – переводчик: Free Dictionary + ML Kit + Tatoeba, кэш в Room, история, авто-добавление
  в «Новые» с отменой, произношение (аудио словаря / TextToSpeech), экран результата. Коммиты 5495be1, 115ae05, fe6a6ab.

## Фаза 2 – проверено
- `./gw build` зелёный: 45 тестов (`:app` 36, `:domain` 9), lint 0 ошибок.
- Круг критики скриншотов переводчика: неактивная кнопка без серой плашки, меньше отступ перед результатом,
  звёздочка по центру слова, в тёмной теме буквы темнеют вместе с маркером.
- **Не проверено:** ML Kit, TextToSpeech и аудио на реальном телефоне по adb (в Robolectric не запускаются).

## Фаза 3 – проверено

  «Я знал, это опечатка» переписывает ту же запись, режим практики трудных слов (`start(practice = true)`) – кнопку
  «Повторить их сейчас» подключить в фазе 4.
- `./gw build` зелёный: `:domain` 104 теста, `:app` 46, lint 0 ошибок. Коммиты a8ada6f, 5108ca9, afdf695 + критика.
- Критика: итог сессии говорит, сколько слов вернулось в «Новые»; подписи «Верно – теперь в коробке N из 5» без
  шаблонной точки-разделителя.
- Отложено в фазу 6: переворот карточки, «улёт» к вкладке «Новые», отключение анимаций по системной настройке.
- Не проверено на телефоне: клавиатура, вибрация.

## Фаза 4 – проверено
- Списки (поиск, сортировка в DataStore, свайп-удаление с «Вернуть», «Вернуть в изучение»), карточка слова,
  статистика из Room Flow (график на своём Canvas, без Vico), серия в `:domain` (`StreakCalculator`),
  «Повторить их сейчас» → практика трудных слов. Коммиты 60a637b, 2440f4a + критика.
- `./gw build` зелёный: `:domain` 122 теста, `:app` 69 + скриншоты, lint 0 ошибок.
- Критика: у графика пол шкалы 4 (одно слово не растягивает столбик на всю высоту, линии сетки = целые числа);
  подпись «Коробка N из 5» на карточке слова; высокие скриншоты `stats_data_full_*`, `word_card_full_*`
  для блоков ниже первого экрана.
- Не проверено на телефоне: свайп, snackbar, переход в практику.

## Решения владельца (действуют дальше)
- Экономный режим: агенты – только Mobile App Builder (один на фазу) и Code Reviewer (один раз в фазе 6);
  один круг критики скриншотов, светлая + тёмная, 360dp; крупный шрифт – только в фазе 6. См. `CLAUDE.md` §3–4.
- Всё скачанное – только внутри `.tools/` (Gradle, SDK, JDK 21, Robolectric). Сборка – только через `./gw`.
  После работы – `./gw --stop`, фоновых процессов не оставлять.
- Источники: без Claude/LLM-фолбэка и без Datamuse. Ключей в проекте нет.
- Эмулятор не ставим; проверка на устройстве – телефон по adb.
- По §17 ARCHITECTURE.md приняты рекомендованные варианты.
