## Готово
- **Фаза 0** – `docs/ARCHITECTURE.md`, `docs/adr/0001-dictionary-sources.md`, `docs/DESIGN_TOKENS.md`.
- **Фаза 1** – скелет, тема, навигация, Room, пустые экраны, Roborazzi (20 скриншотов). Круг критики сделан:

## Фаза 5 – проверено
- `TranslateActivity` (PROCESS_TEXT «Перевести в Lexa» + SEND): нижний лист поверх приложения, тот же `TranslatorViewModel`
  и тот же блок результата (`TranslationResult`), авто-добавление с маркером, «Отменить», «Открыть в Lexa» → карточка слова.
  Правила текста – `SharedText` (≤ 5 слов, ≤ 60 символов, одно предложение, без ссылок).
- Напоминание: переключатель + время (TimePicker) в настройках, POST_NOTIFICATIONS при включении (отказ – строка, как
  разрешить), `ReviewReminderWorker` (HiltWorker) – уникальная one-time работа, сам планирует следующий день (`ReminderTime`).
  Тап по уведомлению → вкладка «Тренировка».
- `./gw build` зелёный: `:domain` 128 тестов, `:app` 93, lint 0 ошибок. Скриншоты: `translate_sheet_*`, `settings_reminder_*`, `settings_*`.
- Скриншот листа – рамка-имитация (scrim + тело листа), настоящий ModalBottomSheet в Robolectric не снимается.
- Не проверено на телефоне: меню выделения в браузере, «Поделиться», реальное уведомление в 19:00, запрос разрешения, TimePicker.

- Критика (основная сессия): на листе перевода «Открыть в Lexa» – текстовая кнопка, маркер остаётся один
  (на слове); переключатель напоминания – чернила вместо маркера. `./gw build` зелёный (`:domain` 128, `:app` 93).

## Решения владельца (действуют дальше)
- Экономный режим: агенты – только Mobile App Builder (один на фазу) и Code Reviewer (один раз в фазе 6);
  один круг критики скриншотов, светлая + тёмная, 360dp; крупный шрифт – только в фазе 6. См. `CLAUDE.md` §3–4.
- Всё скачанное – только внутри `.tools/` (Gradle, SDK, JDK 21, Robolectric). Сборка – только через `./gw`.
  После работы – `./gw --stop`, фоновых процессов не оставлять.
- Источники: без Claude/LLM-фолбэка и без Datamuse. Ключей в проекте нет.
- Эмулятор не ставим; проверка на устройстве – телефон по adb.
- По §17 ARCHITECTURE.md приняты рекомендованные варианты.
